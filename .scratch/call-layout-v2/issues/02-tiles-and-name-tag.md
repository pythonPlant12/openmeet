# 02: Tiles and name tag

**What to build:** Tiles lose the red mute and camera-off badges. The name tag is a dark translucent pill with the name only and a mic-off icon when muted; bottom-centre on phone, bottom-left on desktop; it supports a collapsed form (mic-off icon only, or nothing when unmuted). On touch there is no ⋯ button and tapping the name tag opens that person's menu as a small sheet; desktop keeps ⋯ on hover. Video tiles get an expand icon at the top-right for full screen of that tile. Spec stories 9–19.
